# Acceptance

Automated checks prove source-level behavior and package integrity. They do not prove behavior in a real Obsidian host.

Before a release, test the packaged candidate in an explicitly named disposable Vault on the minimum supported Obsidian version and the current stable version. Cover Reading view; Live Preview double-click and Enter/F2 cell editing; Enter/Escape/Tab, undo/redo, English and Chinese IME; pasted Wiki links and embeds with escaped pipes; HTML-table paste with row/column spans and disabled pass-through; HTML/GFM/TSV/CSV clipboard output; GFM preview confirm/cancel/stale refusal; Sheets Extended migration and conflict warning; Bases-disabled upgrade refusal; ordinary and structural right-click Base-upgrade labels; the explicit multi-row/merged-header and row-header flattening preview; visible merged-data blocker text, exact coordinates/spans, disabled confirmation, and zero writes; upgrade confirmation and failure cleanup; record properties and path-independent membership after rename/move; later-record creation after moving the host note; native Base New adoption into the current host inbox with a stable record ID, collision suffixing, preservation of user moves, and fail-closed ambiguity or move failure; restoration that keeps records; missing-manifest refusal; Source mode preservation; every command; ordinary-table native cell/row/column selections and menus while takeover is disabled; ordinary-table Live Preview and Reading view ownership, full menus, unchanged source, and immediate native restoration while the opt-in setting is toggled; theme-aware column/corner and lighter row-header backgrounds; native-looking borders and owned-table handles hidden at rest but individually revealed for only the hovered, keyboard-focused, or selected row/column; drag selection, insert/delete/move/alignment/merge/split/header menus; all three table layouts in narrow and split panes, with content-left as the fresh default; alternating rows limited to data cells; refusal without content loss; invalid-table diagnostics; settings persistence; light and dark themes; plugin disable/uninstall cleanup; and conflicts with another table plugin.

For Android candidates, also run the current packaged bytes in a named disposable emulator Vault and cover startup, Reading view, Live Preview, two-tap rectangular selection, long-press menus, touch-sized row/column handles, in-place editing, and Chinese/English IME composition. Physical Android is optional enhanced evidence and its absence does not block the shared release closure. Emulator and physical-device results remain separate; record device/AVD, OS/API, Obsidian version, candidate identity, and per-scenario result. Production-Vault deployment is separate and requires explicit authorization for the exact Vault.
