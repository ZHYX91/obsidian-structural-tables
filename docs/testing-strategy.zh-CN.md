# Structural Tables — 测试策略

<!-- section: levels -->
## 层级

测试分为纯核心单元测试、DOM 渲染测试、插件接线测试、打包候选检查和真实 Obsidian 验收，各层结论不得互相替代。

<!-- section: parser-cases -->
## 解析用例

覆盖普通 GFM 默认不接管且显式开启后纳入接管、分隔行至少三个连字符、左右/上下合并、多行表头、行表头、转义记号、管道转义、代码跨度、代码块、带 BOM 且使用两种合法结束记号的 frontmatter，以及 LF/CRLF/CR 换行保留。

<!-- section: invalid-cases -->
## 反例

覆盖缺失锚点、非矩形、跨角色、边缘/多重/带空格 `||`、宽度不一致；断言源码不被修改且诊断稳定。

<!-- section: commands -->
## 命令

覆盖安全合并、非空拒绝、拆分、插入/删除/移动/对齐变换、合并锚点迁移、Wiki 链接管道转义且不重复转义，以及规范格式化；每次候选编辑必须经过重新解析。DOM 测试覆盖普通表格接管与释放、接管后的完整菜单、语义表头角色、把手、原位编辑、Tab 单事务提交和输入法组合态。设置测试覆盖接管默认关闭、纯且幂等的规范化、无版本到 schema 1 的迁移、当前 schema 加载、未来及畸形显式 schema 拒写、不可变串行快照、可见的失败与重试状态，以及卸载 flush。

<!-- section: interchange -->
## 互操作用例

核心测试覆盖多行列表头路径、合并值展开、HTML 语义跨度/scope、CSV 引号、TSV 清理、Sheets Extended 唯一分隔列及其反例。DOM 测试覆盖带 thead/th/td/rowspan/colspan 的 HTML 剪贴板、只有 td 的首行回退、非表格和单列表格不接管。GFM 替换确认时必须重新解析并拒绝过期快照。

<!-- section: base-promotion -->
## Base 升级用例

纯核心覆盖重复/非拉丁/保留 Property key、文件名安全化、列表成员资格、多行/合并列表头与行表头的确定性展平提示、数据区合并阻断的位置及跨度，以及插件 Base metadata 定位。菜单测试区分普通表格的“升级为 Base”和结构表格的“展开结构并升级为 Base”。内存 Vault 事务测试验证被阻断的方案不写入任何文件，并覆盖记录与清单先于源码替换、创建期间表格变化时整目录回收、恢复保留记录、宿主移动后按新目录创建记录、清单缺失/不匹配和目标冲突。

<!-- section: host -->
## 宿主验收

在明确命名的临时 Vault 中测试最低和当前 Obsidian、亮暗主题、默认内容宽度布局、跟随主题的列表头/左上角表头与行表头层级、贴近原生的结构表格边框、把手在闲置/悬停/聚焦/选中状态下逐个隐藏与显现且不会整表铺开、实时预览笔记打开与光标切换、单元格编辑/粘贴/Tab/输入法行为、HTML 表格粘贴与禁用回退、HTML/GFM/TSV/CSV 剪贴板结果、GFM 预览确认/取消/过期拒绝、Sheets Extended 迁移、冲突提示、Base 未启用拒绝、两种右键 Base 升级文案、展平预览、数据合并时禁用确认且不写入、升级确认/失败回收、生成记录与 membership、记录移动/重命名后仍显示、宿主移动后的新建位置、恢复保留记录、清单缺失拒绝、行列把手和全部菜单操作、接管关闭时普通表格保持原生、接管开启时普通表格在实时预览和阅读视图中归插件所有、关闭后立即无损恢复、设置持久化、撤销/重做和插件停用清理。仓库文档截图使用英文临时 Vault、不包含鼠标指针，也不作为生产部署证据。

<!-- section: mobile -->
## 移动端

每个移动端发布候选都必须保留当前 Android 模拟器证据，覆盖启动、阅读视图、实时预览、两点矩形选区、长按菜单、触摸尺寸把手、原位编辑和中英文输入法组合输入。执行时记录 AVD、系统、Obsidian 版本、候选身份和场景结果。Android 真机和 iOS 不在验收范围内。
