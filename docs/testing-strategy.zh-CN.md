# Structural Tables — 测试策略

<!-- section: levels -->
## 层级

测试分为纯核心单元测试、DOM 渲染测试、插件接线测试、打包候选检查和真实 Obsidian 验收，各层结论不得互相替代。

阅读视图回归测试传入完整笔记的 section 文本与源码起止行，并断言后面的普通表格不会被前面的结构表格替换。

<!-- section: parser-cases -->
## 解析用例

覆盖普通 GFM 默认不接管且显式开启后纳入接管、分隔行至少三个连字符、左右/上下合并、多行表头、行表头、转义记号、管道转义、代码跨度、代码块、带 BOM 且使用两种合法结束记号的 frontmatter，以及 LF/CRLF/CR 换行保留。

<!-- section: invalid-cases -->
## 反例

覆盖缺失锚点、非矩形、跨角色、边缘/多重/带空格 `||`、宽度不一致；断言源码不被修改且诊断稳定。

<!-- section: commands -->
## 命令

覆盖安全合并、非空拒绝、拆分、插入/删除/移动/对齐变换、合并锚点迁移、Wiki 链接管道转义且不重复转义、Shift+Enter/单元格编辑菜单/多行粘贴的规范 `<br>` 插入，以及规范格式化。序列化测试断言 ASCII、中文、组合字符和 emoji 的显示列管道对齐，保持 `||`、对齐记号、转义管道、Wiki 链接、代码跨度及 LF/CRLF/CR，并重新解析每个结果。DOM 测试覆盖普通表格接管与释放、接管后的完整菜单、语义表头角色、单元格代理显示对应把手、居中表格的把手坐标、编辑器光标移动和跨表指针转移时清除选区、编辑框不撑宽且只有一层外边框、Tab 单事务提交和输入法组合态。设置测试覆盖接管默认关闭、纯且幂等的规范化、无版本到 schema 1 的迁移、当前 schema 加载、未来及畸形显式 schema 拒写、不可变串行快照、可见的失败与重试状态，以及卸载 flush。

<!-- section: interchange -->
## 互操作用例

核心测试覆盖多行列表头路径、合并值展开、HTML 语义跨度/scope/换行元素、CSV 引号、TSV 清理、Sheets Extended 唯一分隔列及其反例。DOM 测试覆盖带 thead/th/td/rowspan/colspan 的 HTML 剪贴板、`<br>` 变体和块边界换行、Wiki 链接及字面量管道转义、只有 td 的首行回退、非表格和单列表格不接管。GFM 替换确认时必须重新解析并拒绝过期快照。

<!-- section: base-promotion -->
## Base 升级用例

纯核心覆盖原样数字、前导零、空白、规范化重名、非拉丁和保留 Property key，以及方括号引用生成与旧点号引用识别、Windows 设备名含扩展名时的文件名安全化、新旧列表成员资格、等价双字段及无效/冲突字段、多行/合并列表头与行表头的确定性展平提示、数据区合并阻断的位置及跨度、使用 LF/CRLF/CR 换行的插件 Base metadata 定位、波浪线围栏，以及忽略更长围栏内的嵌套示例。菜单测试区分普通表格的“升级为 Base”和结构表格的“展开结构并升级为 Base”。内存 Vault 事务测试验证被阻断的方案不写入任何文件，并覆盖记录与清单先于源码替换、不写入记录自身 ID、创建期间表格变化时整目录回收、恢复保留记录、宿主移动后按新目录创建记录、清单缺失/不匹配和目标冲突。迁移测试覆盖逐文件动作和随开关同步的计数、默认关闭且限于有效成员笔记的旧记录 ID 清理、frontmatter/源码过期与冲突拒绝、Base 重写前的并发完整源码变更、三种换行的 Base 过滤条件替换，以及后续写入失败时只回滚迁移内容并保留无关并发编辑。

<!-- section: host -->
## 宿主验收

在明确命名的临时 Vault 中测试最低和当前 Obsidian、亮暗主题、默认内容宽度布局、把手覆盖时表格起点仍与原生对齐、跟随主题的列表头/左上角表头与行表头层级、所有外边缘的跨度感知边框、合并前后的稳定舒适/紧凑桌面单元格尺寸及粗指针触摸下限、跨行时连续的交替行底色、通过单元格显示对应把手且聚焦/选中状态持续可见、不整表铺开也不被裁切、单元格/行把手/列把手组各一个 Tab 停靠点、LTR/RTL 方向键导航和清晰焦点、焦点离开、编辑器光标切换及跨表指针转移时清除选区、实时预览笔记打开与光标切换、单元格编辑、Shift+Enter/菜单插入换行、多行粘贴、Tab 与输入法行为、浏览器/Excel HTML 表格粘贴（含单元格内换行）与禁用回退、HTML/GFM/TSV/CSV 剪贴板结果、GFM 预览确认/取消/过期拒绝、Sheets Extended 迁移、冲突提示、Base 未启用拒绝、两种右键 Base 升级文案、数字/前导零/空表头 Base 提升、展平预览、数据合并时禁用确认且不写入、升级确认/失败回收、生成记录与 membership、记录移动/重命名后仍显示、宿主移动后的新建位置、恢复保留记录、清单缺失拒绝、行列把手和全部菜单操作、接管关闭时普通表格保持原生、接管开启时普通表格在实时预览和阅读视图中归插件所有、关闭后立即无损恢复、设置持久化、撤销/重做和插件停用清理。仓库文档截图使用英文临时 Vault、不包含鼠标指针，也不作为生产部署证据。

<!-- section: mobile -->
## 移动端

每个移动端发布候选都必须保留当前 Android 模拟器证据，覆盖启动、阅读视图、实时预览、两点矩形选区、长按菜单、触摸尺寸把手、原位编辑和中英文输入法组合输入。执行时记录 AVD、系统、Obsidian 版本、候选身份和场景结果。Android 真机和 iOS 不在验收范围内。
