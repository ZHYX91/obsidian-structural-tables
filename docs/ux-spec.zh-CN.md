# Structural Tables — 交互规范

<!-- section: principles -->
## 原则

源码始终可见、可恢复；渲染负责理解而非改写；可能丢失内容的操作必须拒绝。

<!-- section: live-preview -->
## 实时预览

CodeMirror 光标和选区均位于表格外时显示语义表格。渲染组件内双击单元格或按 Enter/F2 可打开单行原位编辑器；Enter 提交，Escape 取消，Tab 提交并前往下一格。粘贴时会立即转义代码跨度外尚未转义的表格管道，且不重复转义。输入法合成期间不提交，也不切换渲染。

<!-- section: reading-view -->
## 阅读视图

用 `thead`、`tbody`、`th`、`td`、`rowspan`、`colspan` 与合适的 `scope` 渲染。单元格内部继续使用 Obsidian Markdown 渲染。

<!-- section: commands -->
## 命令

插入模板、格式化、向左合并、向上合并、拆分、检查、复制 HTML/GFM/TSV/CSV、预览并展开为普通 GFM，以及迁移 Sheets Extended 分隔列均可从命令面板调用。非空单元格合并时显示说明并保持原文；展开为 GFM 必须先显示可滚动、可选择的结果预览，并在确认时重新校验源表未变化。

<!-- section: interchange -->
## 粘贴与互操作

“保留粘贴 HTML 表格的合并结构”启用时，仅在剪贴板包含可验证的多列表格时接管粘贴；否则保留 Obsidian 原行为。thead 或连续 th 行成为列表头，表体最左侧连续 th 列成为行表头，rowspan/colspan 转换为规范的 `^`/`<`。单元格导入为纯文本。普通 GFM、TSV 和 CSV 输出会重复合并值，并用 ` / ` 连接多行列表头路径；HTML 输出保留语义角色、跨度和 scope。

<!-- section: base-promotion -->
## 升级为 Base

右键普通表格显示“升级为 Base…”，插件接管的结构表格显示“展开结构并升级为 Base…”。操作无需选中整张表，只在已保存笔记内的有效表格上工作，并要求启用 Bases 核心插件。预览显示目标文件夹、记录数量、显示列名到稳定 Property key 的映射、生成的 Base 源码和所有适用的展开规则：多行列表头路径用 ` / ` 连接，合并列表头展开到覆盖的 Property 路径，行表头转为普通 Property，合并行表头值写入每条记录。数据区合并单元格会以行、列和跨度标出并禁用确认，执行层在创建任何文件前再次检查阻断项。有效操作执行期间按钮禁用；创建失败显示原因、保持原表并把本次目录移入废纸篓。

生成 Base 的 metadata 注释保存稳定 table ID 与恢复清单路径。把光标放在该 Base 上，可使用插件命令按宿主当前目录创建空白记录，或预览并恢复原表。恢复明确说明生成记录会保留。记录移动、重命名和整理不显示提示，也不改变成员资格。

<!-- section: table-selection -->
## 表格选区与右键菜单

默认情况下，普通 GFM 表格沿用 Obsidian 原生 Markdown 表格的单元格选区、整行/整列把手和共享事件菜单，可直接创建第一项结构语法。启用“接管普通 Markdown 表格”后，光标不在表内的普通 GFM 表格使用与结构表格相同的插件控件、把手、拖动选区、原位编辑、完整编辑菜单、布局、密度和交替行底色，且不改变源码；关闭设置会立即刷新已打开视图并恢复原生行为。普通表格和插件接管的结构表格都会在右键菜单提供相应的 Base 升级入口，无需选中整张表。每个插件把手仅在对应行列控件被悬停、键盘聚焦或选中时显示，单元格获得焦点时不得让全部把手同时出现；同时保留已有的原生风格整列选中效果。矩形多单元格选区提供“合并所选单元格”；单个合并单元格提供“拆分合并单元格”。除左上角外存在内容、选区跨角色边界或只包含已有合并区域的一部分时，拒绝合并并保留源码。

从表格顶部开始的完整行选区可以设置列标题行；从最左侧开始且覆盖所有表格行的完整列选区可以设置或取消行标题列。插件接管的表格菜单还可插入、安全删除、移动和对齐所选行列：在合并区域内部插入会扩展该区域；删除锚点但合并区域仍存在时会迁移内容；任何会丢弃非空内容、拆散合并矩形或跨越表头边界的操作都会被拒绝。接管关闭时，普通表格继续使用 Obsidian 原生菜单和把手行为。

<!-- section: diagnostics -->
## 诊断

无效结构显示红色边缘和可读原因；不替换阅读视图中的原表格，也不在编辑器中隐藏源码。

<!-- section: settings -->
## 设置

使用 Obsidian 原生设置控件和顶部分页，分为“常规”“视图”“外观”。活动页签同时使用强调色下划线和半粗字重，页签基线与内容面板之间保留稳定间距。语言、HTML 表格粘贴转换和启动冲突提示位于第一个“常规”页，自动语言显示为“跟随 Obsidian”并附带说明。“视图”提供默认关闭的“接管普通 Markdown 表格”，说明必须明确源码保持标准、关闭后恢复原生表格，并提示可能与其他表格插件冲突。新安装默认使用“适应内容宽度—靠左”，“外观”也提供“适应内容宽度—居中”和“适应窗格宽度”。已渲染的列表头与左上角表头使用较强的主题派生背景，行表头使用较浅背景，交替行仅作用于数据单元格。布局只改变整个表格的位置和宽度，不改变单元格内容对齐。控件标签与说明支持英文和简体中文。
